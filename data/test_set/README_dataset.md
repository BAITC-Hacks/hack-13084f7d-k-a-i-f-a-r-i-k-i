# Синтетический тестовый комплект для кейса «Анализ оргструктуры»

Компания вымышленная: АО «КазЭнергоСеть». Все совпадения случайны.

## Состав
- `before/` — состояние до реорганизации: оргструктура (xlsx, приказ 18-п от 10.02.2025) и 9 положений (docx + 2 pdf).
- `after/` — после реорганизации: приказ № 45-п от 15.01.2026 (pdf), новая оргструктура (xlsx) и 8 положений (docx + 1 pdf).
- `ground_truth.json` — эталон: что агент обязан найти, с документами и пунктами.

## Что заложено
| Тип | Что | Где |
|---|---|---|
| Объединение | ДЗ + ДЛ → ДЗЛ | приказ п.1 |
| Упразднение | ОДР | приказ п.2 |
| Переименование | ДИТ → ДЦТ | приказ п.3 |
| Создание | ДУР | приказ п.4 |
| Потеря L1 | Инвентаризация складских запасов | before/ДЛ п.3.4 |
| Потеря L2 | Ведение реестра договоров | before/ОДР п.3.3 |
| Дубль D1 | Мониторинг рынка поставщиков | after/ДЗЛ п.3.3 и КД п.3.5 |
| Дубль D2 | Политика информационной безопасности | after/ДЦТ п.3.6 и СБ п.3.2 |
| Конфликт C1 | Проведение закупок + контроль закупочных процедур | after/ДЗЛ п.3.2 и п.3.9 |
| Бонус | Закупка + приёмка ТМЦ | after/ДЗЛ п.3.2 и п.3.6 |
| Ловушка | «Анализ рынка» в КД — это не дубль | after/КД п.3.2 |

## Как использовать
Прогнать агент на `before/` и `after/`, сравнить findings с `ground_truth.json` (скрипт eval.py: совпадение по doc + clause).
Считать: найдено X из 2 потерь, 2 дублей, 1 конфликта; ложных срабатываний Y.
